# Standard-Einrichtung

Lege hier eine Exportdatei aus der App ab (⚙️ → Darstellung → **Exportieren**) und benenne sie
`default-setup.json`. Der Build packt Bild, Video und Einstellungen dann ins Dateisystem des
Web-Installers – nach dem Flashen ist alles sofort aktiv, ohne Import.

Hinweis: Diese Datei wird mit dem Repo und dem Web-Installer veröffentlicht. Lege hier nur Inhalte ab,
die du selbst erstellt hast und veröffentlichen darfst.
